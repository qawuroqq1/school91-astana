# Официальный сайт школы №91 г. Астаны

Трёхъязычный (KZ / RU / EN) сайт школы с панелью управления (CMS).
Работает на **Node.js 22 + встроенной SQLite** и не требует установки внешних пакетов: `npm install` не нужен.

![Стек](https://img.shields.io/badge/Node.js-22.18%2B-339933) ![Зависимости](https://img.shields.io/badge/зависимости-0-0b1f3a) ![Языки](https://img.shields.io/badge/языки-KZ%20%7C%20RU%20%7C%20EN-179bab)

---

## Быстрый старт

```bash
# нужен Node.js 22.18 или новее (проверьте: node -v)
npm start
```

Откройте:

- сайт: http://localhost:3000 (перенаправит на `/kz`, `/ru` или `/en` по языку браузера);
- админ-панель: http://localhost:3000/admin.

При первом запуске создаётся администратор. Логин и пароль выводятся в консоль.
Задать их заранее можно так:

```bash
ADMIN_EMAIL=director@school91.kz ADMIN_PASSWORD='надёжный-пароль' npm start
```

Другие команды:

| Команда | Что делает |
|---|---|
| `npm run dev` | запуск с автоперезапуском при изменении кода |
| `npm test` | сквозные тесты: обход всех страниц на трёх языках, формы, админка, роли, безопасность загрузок |
| `npm run typecheck` | проверка типов TypeScript (нужен `tsc` и `@types/node`) |
| `npm run reset-db` | удалить базу (при следующем запуске создастся заново) |

## Что внутри

**Публичная часть**
- Главная страница: первый экран, быстрый доступ, новости и анонсы, объявления, блок «О школе», показатели «в цифрах» (только подтверждённые), фотогалерея, полезные ссылки, карта и контакты.
- 8 разделов с мегаменю: «О школе», «Ученикам», «Родителям», «Учителям», «Воспитательная работа», «Открытый бюджет», «Официальная информация», «Новости». Структура сверена с сайтом школы №77.
- Новости: категории, фильтр по годам, пагинация, отдельные страницы, архив, комментарии с модерацией, RSS-лента для каждого языка.
- Поиск по страницам, новостям и документам с подсветкой совпадений.
- Контакты с формой обратной связи и **блог директора** (вопрос → ответ → публикация после модерации).
- Страницы сотрудников (директор, администрация, педагоги), документы с указанием языка оригинала, фотогалерея с лайтбоксом.
- **Версия для слабовидящих**: три размера шрифта, чёрно-белая схема и схема «белым по чёрному», отключение изображений.
- Страницы 404 и 500, хлебные крошки, карта сайта.

**Три языка**
- Отдельные маршруты `/kz`, `/ru`, `/en`. Переключатель ведёт на ту же страницу другого языка.
- Весь интерфейс переведён и хранится централизованно: `src/i18n/{kz,ru,en}.ts`. Любую надпись можно переопределить в админке («Переводы»).
- Языки не смешиваются: новость без перевода не показывается в списке этого языка, а её страница предлагает доступные версии. Документ без перевода показывается с пометкой «Язык документа».
- `hreflang`, `x-default`, `og:locale`, `sitemap.xml` с альтернативными языками.

**Админ-панель (`/admin`)**
- Роли: **администратор** (всё) и **редактор** (контент без настроек и пользователей).
- Новости (3 языка, обложка, черновик/публикация, закрепление, дата мероприятия), страницы (визуальный редактор, вставка фото и таблиц), документы (загрузка нескольких файлов), сотрудники, галерея (альбомы, подписи), объявления (с периодом показа), сообщения, блог директора, модерация комментариев, переводы интерфейса, настройки школы (название, контакты, карта, соцсети, фото первого экрана, логотип, показатели, полезные ссылки), пользователи, статистика посещений, журнал действий.

**Безопасность**
- Пароли хранятся как scrypt-хеш, сессии в HttpOnly-cookie, CSRF-токены во всех формах админки.
- Ограничение попыток входа и отправки форм, honeypot и проверка времени заполнения против спам-ботов.
- Очистка HTML из редактора (никаких `<script>`, `on*`, `javascript:`).
- Загрузки проверяются по расширению и сигнатуре файла, SVG и HTML запрещены, документы отдаются с `CSP: sandbox`.
- Заголовки безопасности: CSP, `X-Content-Type-Options`, `Referrer-Policy`, `X-Frame-Options`.

**Дизайн и анимации**
- Дизайн-система в `public/css/site.css`: палитра (глубокий тёмно-синий `#0b1f3a`, бирюзовый акцент `#179bab`, тёплый янтарный `#e5a13a`), шрифты Manrope + Inter (с поддержкой казахских букв), шкала размеров, радиусы, тени.
- Собственная motion-система без библиотек: заголовки появляются по словам, элементы — при прокрутке (с задержкой по очереди), счётчики, мягкий параллакс фото, «магнитные» кнопки, анимированное мегаменю и мобильное меню, лайтбокс со свайпами, плавные переходы между страницами (View Transitions API).
- Анимируются только `transform` и `opacity`. Учитывается `prefers-reduced-motion`; в версии для слабовидящих анимации отключены.

## Достоверность информации

В проекте **нет выдуманных данных** о школе: адрес, телефон, ФИО, история, количество учеников и достижения не заполнены. На сайте такие поля показываются как «Уточняется», страницы без текста — как «Раздел наполняется». Изображение на первом экране — временная иллюстрация с подписью; логотип — временная эмблема.

Заполнены только общедоступные факты (страница «Государственные символы») и одна правдивая новость о запуске сайта.

**Что заполнить в первую очередь** (Админка → Настройки / Страницы / Сотрудники):
1. Адрес, телефон, эл. почта, режим работы, координаты для карты, соцсети.
2. Логотип школы и фото здания для первого экрана.
3. Директор и администрация, история, паспорт школы, правила приёма.
4. Нормативные документы и материалы «Открытого бюджета».

## Размещение на хостинге

Подойдёт любой VPS или хостинг с Node.js 22.18+ (например, PS Cloud, Hoster.kz VPS, Timeweb Cloud).

```bash
git clone <репозиторий> school91 && cd school91
export SITE_URL=https://school91.edu.kz   # публичный адрес (canonical, sitemap, RSS)
export COOKIE_SECURE=1                     # если сайт работает по HTTPS
export ADMIN_EMAIL=... ADMIN_PASSWORD=...
npm start
```

Рекомендуется:
- запускать через `systemd` или `pm2`, а перед ним поставить Nginx/Caddy с HTTPS;
- каждый день делать резервную копию папки `data/` (база `school.db` и загруженные файлы `uploads/`). Этого требует техспецификация.

Пример `systemd`-сервиса:

```ini
[Unit]
Description=School 91 website
After=network.target

[Service]
WorkingDirectory=/opt/school91
Environment=PORT=3000 SITE_URL=https://school91.edu.kz COOKIE_SECURE=1
ExecStart=/usr/bin/node --disable-warning=ExperimentalWarning src/server.ts
Restart=always
User=www-data

[Install]
WantedBy=multi-user.target
```

> GitHub Pages для этого сайта не подходит: Pages отдаёт только статические файлы, а здесь есть сервер (админка, база, формы).

### Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3000` | порт сервера |
| `SITE_URL` | `http://localhost:3000` | публичный адрес сайта |
| `DATA_DIR` | `./data` | где хранить базу и загрузки |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` | — | первый администратор (только при пустой базе) |
| `COOKIE_SECURE` | — | `1`, если сайт работает по HTTPS |
| `MAX_UPLOAD_MB` | `25` | максимальный размер загружаемого файла |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | — | мгновенные уведомления о новых сообщениях, вопросах директору и комментариях |
| `LOG_REQUESTS` | — | `1` — писать каждый запрос в журнал |

## Структура проекта

```
src/
  server.ts            HTTP-сервер, статика, обработка ошибок
  config.ts            настройки из переменных окружения
  site/structure.ts    дерево разделов и страниц (одно на все языки)
  i18n/                словари интерфейса kz / ru / en, форматирование дат
  db/                  схема SQLite и миграции, запросы, настройки, начальные данные
  lib/                 шаблоны с экранированием, роутер, cookies/сессии/CSRF, загрузки, уведомления
  routes/              публичные маршруты, админка (ядро и контент)
  views/               шаблоны страниц: layout, главная, разделы, новости, формы; админка
public/
  css/site.css         дизайн-система и стили сайта
  css/admin.css        стили панели управления
  js/site.js           меню, поиск, лайтбокс, версия для слабовидящих, анимации
  js/admin.js          вкладки языков, визуальный редактор, подтверждения
  img/                 временные логотип, иллюстрации, OG-картинка
tests/site.test.ts     сквозные тесты
data/                  база и загрузки (создаётся автоматически, в git не попадает)
```

### Как добавить раздел или страницу

Отредактируйте `src/site/structure.ts`: добавьте пункт в нужный раздел с названиями на трёх языках. При следующем запуске страница появится в меню, карте сайта и админке.

## Почему не Next.js

Изначально рассматривался стек Next.js + Prisma + PostgreSQL. Проект сделан без внешних зависимостей, чтобы его было легко разместить и поддерживать (нет `node_modules`, нет сборки, база — один файл). Архитектура разделена на слои (структура, данные, шаблоны, маршруты), поэтому при необходимости её можно перенести на Next.js.
